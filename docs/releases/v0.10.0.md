# Talos v0.10.0

This pre-1.0 minor release consolidates TUI activity presentation, capability
distribution and bounded Auto review corrections since v0.9.2.

## Highlights

- Completed reasoning is collapsed by default, with independent click-to-expand
  headers, preserved selection/export boundaries and shared continuation padding.
- Live thinking shows width-aware line counts above ten rolling body rows.
  Tool activity is correlated by call ID, including same-name calls and reversed
  results, without repeating completed result bodies in the live preview.
- Thinking preserves the themed prefix and muted base with a slower outward-only wave.
- Numeric permission shortcuts have completed their native IME acceptance.
- Root Rust/Python language Plugin sources, offline provider packaging and
  consented bounded Bundle resolution are available with their existing safety gates.
- The bounded read-only browser provider connector retains its SSRF, redirect,
  response-size and link-scheme boundaries; this is not browser automation.
- Auto review distinguishes safe diagnostic failure categories, separates token
  and UTF-8 byte limits, and uses the enclosing permission deadline instead of a
  fixed eight-second cap. GLM-5.3 Auto requests use supported low-effort thinking;
  ordinary conversation and other models retain their existing request settings.

## Rust API Migration

ADR-080 adds `UiOutput::ToolActivity`. External exhaustive matches must add this
variant. Clients that do not render transient activity may ignore it. Existing
`ToolCall` and `ToolResult` events remain the durable history path; do not append
activity metadata as a second history entry. Activity IDs are response-scoped,
and `ResponseStarted` resets that transient namespace.

The additive `LanguageModel::stream_auto_review` method defaults to the existing
bounded decision method. Custom adapters retain their current behavior unless
they explicitly implement a request-local Auto reasoning policy.

## Boundaries

The GPUI Desktop mock and settings page are source-only, not a released Desktop
product. Deferred accessibility/device acceptance remains unverified. No Desktop
archive or `talos-desktop` crate is published. `talos-models` remains unpublished.

Auto changes do not grant new permissions, enable automatic retries, or remove
transport, cancellation, output-size, stale-context or final admission checks.
Model-catalog reasoning-variant coverage remains a separately planned follow-up.
