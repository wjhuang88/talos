## Boundaries And Recovery

Never publish `talos-models`, `talos-desktop`, or any other manifest with
`publish = false`. Desktop mock delivery is not a released Desktop product.
Do not move a failed tag, overwrite published versions, or automatically yank.
Record a failed immutable action and use a new patch version for a source fix.
Never disclose registry tokens. Keep unrelated local changes recoverable until
their exact preservation is verified; do not discard the synchronization stash
merely because `stash apply` partially succeeded.

ADR-080 requires external exhaustive matches on `UiOutput` to handle the new
`ToolActivity` variant. Legacy history events remain exactly once; transient
activity metadata must not be persisted as duplicate history.
