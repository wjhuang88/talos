# Release 0.6.0 Closeout

**Status**: In Progress — release preflight passed; commit and tag pending

## Objective

Publish `v0.6.0` as the next pre-1.0 minor release after `v0.5.0`, carrying the accepted
application-owned TUI renderer, agent-mediated image inspection, adaptive transcript projection,
and safe shared Skill discovery through the standard tag-driven release workflow.

## Version Decision

The maintainer explicitly selected `v0.6.0` on 2026-07-28. A minor version is appropriate because
the product changes default capability discovery, adds pre-1.0 runtime APIs, and materially changes
the interactive terminal renderer. This is a product release gate only: the v0.6 Runtime
Productization Program remains In Progress, I164 remains Active, and REL-002 remains NO-GO.

## Release Boundary

- Includes the accepted Alternate-Screen application-owned full-frame TUI renderer and logical
  history navigation.
- Includes agent-mediated `read_image` with capability, permission, and bounded decode checks.
- Includes adaptive tool/history projection across narrow, wide, CJK, styled, and fill content.
- Includes default shared `~/.agents/skills/` discovery with opt-out and safe symbolic-link policy.
- Excludes crates.io publication, stable 1.0 SDK guarantees, remote control, and any v1.0 claim.

## Required Validation

- Synchronize workspace and internal path-dependency versions to `0.6.0`.
- Synchronize current README and EN/zh-CN public-site release surfaces to `v0.6.0`.
- Run `./scripts/release_preflight.sh v0.6.0` with the repository-pinned Rust toolchain.

- Review the staged release diff for secrets and unrelated changes.
- Commit, create immutable annotated tag `v0.6.0`, and push the commit and tag to `origin`.

- If preflight fails, do not create a tag; fix the release commit and rerun it.
- If the tag workflow fails after tag push, preserve `v0.6.0` and publish a new patch tag after
