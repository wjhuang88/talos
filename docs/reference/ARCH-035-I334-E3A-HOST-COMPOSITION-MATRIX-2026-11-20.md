## Source/feature graph to preserve

- `crates/talos-runtime/Cargo.toml`: `default = []`; `local-storage` opts in Memory, Evolution and Exploration dependencies. A feature-on Rust unit test exercises the additional host-facing selector, without changing published API or runtime default features.
- `crates/talos-cli/Cargo.toml`: runtime features `shared-composition, language-provider`, no `local-storage`. Keeping this unchanged is part of E3a's production CLI no-op decision.
- `crates/talos-desktop/Cargo.toml`: runtime feature `shared-composition`; Desktop production source and features remain unchanged.
- E2 `RuntimeBuilder::durable_session_from_custom_local_profile` selects only an explicit custom durable Session binding. It is **not** a drop-in replacement for default CLI reconciliation or Desktop read-only Existing mode.
