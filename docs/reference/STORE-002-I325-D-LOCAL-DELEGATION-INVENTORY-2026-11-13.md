## Seven capability categories and authority

- Log: current SessionStore TLOG/JSONL, operational as a domain log only.
- Relational: current SQLite domain stores for Session/Pending/Todo, Memory, Evolution and Exploration. SQL/transactions remain domain-owned; no generic SQL provider is bound.
- LexicalSearch: Memory and Exploration FTS5 through accepted domain traits; SessionIndex exists separately as a derived session search projection.
- Object: no shared executable ObjectProvider; existing local files remain owned by their current hosts.
- VectorSearch: unavailable at storage provider layer; graph recall is not vector search.
- Embedding: unavailable as dedicated storage-layer provider; model providers are not implicitly storage providers.
- Rerank: unavailable as standalone provider; existing domain BM25/score order remains intact.

The seven StorageCapabilityKind values and CapabilityRegistry are metadata identities, not binding, readiness or execution guarantees.
