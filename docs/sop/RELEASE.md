# SOP: Release Routing

## Purpose

Provide the governance capability entrypoint for release work without
duplicating the normative release procedure.

## Normative Procedure

All version, build, tag, publication, and GitHub Release work is governed by
[`RELEASE-WORKFLOW.md`](RELEASE-WORKFLOW.md). Read and follow that document in
full before any release mutation.

This routing page does not authorize a release and does not replace any gate in
the normative procedure. If the owner task or Board says NO-GO, release work
remains prohibited.
