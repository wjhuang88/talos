# Desktop Icons

SVG originals downloaded without modification from Lucide release `1.46.0`:
`https://github.com/lucide-icons/lucide/tree/1.46.0/icons`.

The GitHub latest-release endpoint reported this version on 2026-09-17. These are
fixed, embedded presentation assets, not a runtime network dependency. GPUI renders
them using the existing SVG support. The adjacent LICENSE retains Lucide ISC and
